  步驟 3：修改 Claude Desktop 設定檔

  Claude Desktop 的 MCP 設定放在：

  ~/Library/Application Support/Claude/claude_desktop_config.json

  要在裡面加上這段：

  {
    "mcpServers": {
      "filesystem": {
        "command": "/opt/homebrew/bin/npx",
        "args": [
          "-y",
          "@modelcontextprotocol/server-filesystem",
          "/Users/gilbert.hung/Documents/transfor"
        ]
      }
    }
  }

  command 用的是 npx 的完整路徑，因為從 Dock 開的 Claude Desktop 通常讀不到
  Homebrew 的 PATH，只寫 npx 可能會找不到。

  如果這個檔案已經有其他設定（例如其他 mcpServers 或 preferences），要把
  filesystem 併進去，不能整個蓋掉。

  要我先看檔案現在的內容，再幫你併進去嗎？還是你想自己改？
